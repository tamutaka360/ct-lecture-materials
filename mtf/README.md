# MTF とは — 縞が細かくなると、濃淡が消えていく

診療放射線技師課程「CT撮影技術学」／CTの性能評価（空間分解能）の講義用インタラクティブ教材です。

クリック（またはキーボード操作）で1段階ずつ進み、
**縞が細かくなるほどコントラストが失われていく**様子と、
それをグラフにしたものが **MTF（変調伝達関数）** であることを順に確認できます。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 解説つきの公開ページ（SVGを埋め込み済み・単体で動作） |
| `anim_mtf.svg` | アニメーション本体。ブラウザで直接開いても動きます |

## 操作方法

- 図をクリック、またはページ下の **進む ▶／◀ 戻る／最初から ↺** ボタン
- キーボード： `Space` `→` `Enter` で進む・`←` で戻る・`Home` で最初から

## GitHub Pages で公開する

リポジトリの Settings → Pages で公開ブランチを指定すると、
`https://<ユーザー名>.github.io/<リポジトリ名>/mtf/` で表示されます。

## 注意

グラフの MTF 曲線は説明用のモデル曲線であり、特定装置の実測値ではありません。
